## 🎬 HOW TO PROCEED

### Step 1: Download & Install (2 min)
```bash
git clone [your-repo]
cd timetravel-agency
npm install
```

### Step 2: Run Local (1 min)
```bash
npm run dev
# See: http://localhost:3000 ✨
```

### Step 3: Build for Deployment (1 min)
```bash
npm run build
npm start
```

### Step 4: Deploy to Vercel (2 min)
```bash
vercel --prod
# Get your public URL! 🚀
```

### Step 5: Submit on Moodle (5 min)
```
→ Read LIVRABLE.md
→ Upload files (each member)
→ Fill in URLs + team names
→ Click "Send" (not "Draft"!)
→ Done! 🎉
```
