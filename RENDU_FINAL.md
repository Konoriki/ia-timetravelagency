## 📦 Installation & Exécution

### Installation Locale
```bash
git clone <repo-url>
cd timetravel-agency
npm install
npm run dev
```
Accès: http://localhost:3000

### Déploiement Production
```bash
npm run build
npm start
# OU déployer sur Vercel avec 1 clic
```
