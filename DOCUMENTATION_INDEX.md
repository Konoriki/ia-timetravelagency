## 🎬 Workflows Courants

### "Je commence, que faire?"
```
1. QUICK_START.md (5 min)
2. npm install
3. npm run dev
4. Voir sur http://localhost:3000
5. Lire README.md pour comprendre projet
```

### "Je veux modifier le code"
```
1. README.md - Comprendre features
2. PROJECT_STRUCTURE.md - Trouver le fichier
3. Modifier le composant
4. npm run dev
5. F12 pour déboguer
```

### "Je veux déployer"
```
1. DEPLOYMENT.md - Lire guide complet
2. npm run build (tester localement)
3. Git add + commit + push
4. Déployer sur Vercel (1 clic)
5. Tester URL publique
```

### "Je veux améliorer l'app"
```
1. AI_PROMPTS.md - Choisir prompt
2. Copier prompt dans Cursor/Windsurf
3. Générer code
4. Tester localement
5. Valider + commit
```

### "Je dois remettre le projet"
```
1. RENDU_FINAL.md - Lire checklist complète
2. Vérifier tout fonctionne
3. Préparer GitHub + Vercel
4. PHASES_SUMMARY.md - Vérifier livrables
5. Remplir RENDU_FINAL.md
6. Uploader sur Moodle (chaque membre!)
```
