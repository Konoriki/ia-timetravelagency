## 🚀 Comment Démarrer

### 1. Clone & Install (2 min)
```bash
git clone <votre-repo>
cd timetravel-agency
npm install
```

### 2. Run Local (1 min)
```bash
npm run dev
# Voir sur http://localhost:3000
```

### 3. Build & Deploy (5 min)
```bash
npm run build
vercel
# Obtenir URL publique
```
